# CONTRIBUTION GUIDELINES

## Welcome to DATAMIND-UK!

Thank you for joining **DATAMIND**, the UK's Health Data Research Hub for Mental Health. Our mission is to harness the UK’s rich mental health data, enabling collaborative research. **DATAMIND-UK**, our official **GitHub Organization account**, brings together researchers and developers passionate about **mental health data science**.

By contributing to **DATAMIND-UK**, you are joining a vibrant community fostering collaboration, discussion, and open science. Whether you are a researcher, developer, or enthusiast, your input is valuable.

For more information about **DATAMIND**, visit [www.datamind.org.uk](https://www.datamind.org.uk).

## Getting Started with Git and GitHub
If you're new to Git or GitHub, we recommend starting with these resources:
- GitHub's [Guide to Contributing](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project).
- GitHub [Organizations Overview](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/about-organizations).
To begin contributing to **DATAMIND-UK**, ensure you:
- Have a **GitHub account** ([GitHub](https://github.com/)).
- Are familiar with Git and GitHub workflows (e.g., forking, branching, pull requests).
- Review [GitHub's guide to contributing](https://docs.github.com/en/get-started/quickstart/contributing-to-projects).

## Working with DATAMIND-UK
Once you are a **DATAMIND-UK** member, you can:
- **[Create new repositories](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository)** or [bring your existing repositories](https://docs.github.com/en/repositories/creating-and-managing-repositories/transferring-a-repository#transferring-a-repository-owned-by-your-personal-account) within the organization.
- By doing so, you will be **Transferring ownership** of the repository to **DATAMIND-UK** while retaining full control, including deciding who has what access to it.
- **Manage repository access** for contributors.
- Alternatively, if you do not wish to **Transferring ownership** **fork your repository** into **DATAMIND-UK**. ⚠️ *However, this requires careful maintenance to keep versions updated.*

## Managing Project Repositories
You maintain full control over your repositories within **DATAMIND-UK**. While public availability is encouraged, the decision is entirely yours.

### Why Add Repositories to DATAMIND-UK?
- **Visibility**: Increases the visibility of your project within the relevant research community.
- **Team Access Control**: GitHub Organizations allow structured team management.

If you wish to be added to **DATAMIND-UK**, complete the **[membership form](https://github.com/DATAMIND-UK/.github/raw/refs/heads/main/docs/membership_form.docx)** and send it to **[datamind@swansea.ac.uk](mailto:datamind@swansea.ac.uk)** with the subject **"[GitHub] Organization Access"**.

## Checklist for Contributed Code
Before submitting code, ensure:
- **Code Quality**: Follows [PEP 8](https://www.python.org/dev/peps/pep-0008/) (for Python).
- **Tests**: Includes unit tests for new functionality.
- **Documentation**: Provides clear instructions and usage guides.
- **Linting**: Passes linting checks (`black`, `flake8`, etc.).
- **Compatibility**: Works with existing dependencies.
- **Commit Messages**: Are clear and descriptive.

## Licensing
We **recommend** the **MIT License** for your projects within DATAMIND-UK. It’s a permissive, open-source license that allows for broad reuse while ensuring attribution.

To add this license to your repository:

- Create a file called`LICENSE`.
- Paste the MIT License text.
- Update the year and your name/project owner name.



Read more about the **MIT License** [here](https://opensource.org/licenses/MIT).

## Linking GitHub with Other Tools
**DATAMIND-UK** supports integration with external tools for research efficiency.

### GitHub + OSF
[Open Science Framework (OSF)](https://osf.io/) is a research management tool allowing you to document all project steps, from planning to publication. OSF enables:
- **Flexible privacy settings:** Decide which parts of your research are private and which are public.
- **Embargoed data release** and controlled access.
- **Integration with tools** like GitHub.

Follow [this guide](https://help.osf.io/article/211-connect-github-to-a-project) to link your **GitHub repository** with **OSF**.
